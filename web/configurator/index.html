simple-matter Web Configurator

汎用 Matter ファームウェアの構成・個体プロビジョニング・書き込みをブラウザだけで行う (docs/design/generic-firmware.md §6.3 / §9.5)。 Chrome / Edge 系のみ(Web Serial)。すべてクライアントサイドで完結し、 鍵や passcode が外部に出ることはありません。

② 個体情報(discriminator / passcode / SPAKE2+ verifier)

デバイスへ渡すのは iterations / salt / w0‖L だけで、passcode は焼きません (Matter のセキュリティ要件)。検算: cargo run -p smctl -- pase-verifier <passcode> --salt <hex> --iterations <n>

④ スクリプト(WASM → smscript イメージ)

ブラウザ内 AssemblyScript コンパイル(asc)は vendor 容量の都合で Phase E' に分離しました(binaryen だけで 13.6 MB)。当面は ローカルで npx asc / cargo build --target wasm32-unknown-unknown してできた .wasm をここに投入してください。 エディタの内容はローカル保存用で、コンパイルはしません。
